# Run checklist

Before phase 3
- [ ] FAL_KEY is set as an environment variable (not written in any file)
- [ ] Product images are PNG or JPG, product clearly visible
- [ ] prompts.json parses without errors
- [ ] Person approved sample prompts and the cost estimate (count x $0.08 at 1K)

Test run (about 5 templates)
- [ ] num_images is 1, one output folder per template
- [ ] Product matches the real packaging
- [ ] Text spelled right and inside its area
- [ ] Brand colours and font style match the DNA

Full run
- [ ] Failures logged per template id, retried one by one
- [ ] Human review of claims, offers, reviews and logos before any ad goes live
